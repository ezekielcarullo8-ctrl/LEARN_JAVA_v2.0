Java Fundamentals LibraryQuick summaries · Syntax · Examples

1. Variables & Data Types

Variables store values that your program can use and update. Choose a type that matches the data.

int age = 18; double price = 99.50; String name = "Ana"; boolean enrolled = true;
Common types: int (whole numbers), double (decimals), char (single character), String (text), boolean (true/false).

2. Output & Input

Print information to the console. println adds a line break; print does not. Scanner can read user input.

System.out.println("Hello!"); System.out.print("Name: "); Scanner sc = new Scanner(System.in); String input = sc.nextLine();
When using Scanner, add import java.util.Scanner; above your class.

3. Operators

Arithmetic operators perform calculations; comparison and logical operators form conditions.

+ - * / % == != > < >= <= && || ! value += 2; value++;
Use == for equality checks, not = (assignment). Integer division discards the fractional part.

4. if / else & switch

Branch code based on conditions. Conditions evaluate to true or false.

if (score >= 75) { // one branch } else { // other branch } switch (choice) { case 1: break; default: break; }
Use braces to group statements. A switch case often needs break to avoid falling through.

5. Loops

Loops repeat code. Use for when iteration is count-based, while when a condition controls repetition.

for (int i = 0; i < 5; i++) { System.out.println(i); } while (condition) { // repeated work }
Ensure the loop condition eventually changes or becomes false to avoid an infinite loop.

6. Arrays

Arrays hold multiple values of the same type. Indexes start at zero.

int[] scores = {80, 92, 75}; System.out.println(scores[0]); for (int score : scores) { System.out.println(score); }
Use array.length to get the number of elements. The last valid index is length - 1.

7. Methods

Methods package reusable instructions. Parameters pass information in; return sends a result back.

static int add(int a, int b) { return a + b; } // call it: add(2, 3)
Use void for methods that do not return a value. A return type must match the value returned.

8. Classes & Objects

A class defines a blueprint. Objects are instances created from that blueprint; fields hold state and constructors initialize it.

class Student { String name; Student(String name) { this.name = name; } } Student s = new Student("Ana");
this refers to the current object. Constructor names match the class name and have no return type.

9. Encapsulation

Keep fields private and expose controlled access with methods when appropriate.

private int level; public int getLevel() { return level; } public void setLevel(int v) { level = v; }
Encapsulation protects object state and lets validation happen in one place.

10. Constructors

A constructor is a special method that builds a new object. It runs automatically when you use the new keyword and initializes the object's fields.

class Student { String name; int age; // constructor — same name as the class Student(String name, int age) { this.name = name; // this.name = the field this.age = age; } } // new calls the constructor Student s = new Student("Ana", 18);
Rules: the constructor name must match the class name, it has no return type (not even void), and this.field assigns a parameter to a field when names are the same.
