Java Fundamentals LibraryQuick summaries · Syntax · Examples

1. Public Class & main

Every Java program lives inside a public class. The class name must match the filename. Execution always starts at public static void main(String[] args).

public class CampusEats { public static void main(String[] args) { System.out.println("Welcome!"); } }
Syntax: public class ClassName { public static void main(String[] args) { ... } }. Watch out: missing public; class name that does not match the file; code written outside main.

2. Variables & Data Types

A variable is a named box that stores a value. Declare the type so Java knows the kind of data.

String customerName = "Carlos Mendoza"; double mealPrice = 120.00; int quantity = 3; boolean hasActiveID = true;
Common types: int, double, String, boolean. End every statement with a semicolon. Watch out: writing string instead of String.

3. Operators

Operators perform work on values: arithmetic (+ - * / %), comparison (== != > <), logical (&& || !).

double baseTotal = mealPrice + drinkPrice; double vat = baseTotal * 0.12; boolean silver = points >= 50 && points < 100;
Use == for comparison, not =. Integer division drops the fraction; prefer double for money.

4. Conditionals (if / else if / else)

Conditionals choose which block of code runs. Always use braces.

if (hasActiveID == false) { System.out.println("Invalid ID."); } else if (studentPoints >= 100) { System.out.println("Gold Tier"); } else if (studentPoints >= 50) { System.out.println("Silver Tier"); } else { System.out.println("Bronze Tier"); }
Test the most restrictive or special cases first. Watch out: using = instead of ==.

5. Loops (for / while)

Loops repeat a block. for is ideal when you know how many times; while when a condition controls the duration.

for (int count = 6; count >= 1; count--) { if (count <= 2) { System.out.println("LOW STOCK ALERT!"); } }
Always make the condition eventually false. break exits early; continue skips to the next pass.

6. Arrays & Parallel Arrays

An array holds a fixed number of values of the same type. Parallel arrays keep related data at the same index.

String[] mealNames = {"Lugaw", "Egg Sandwich"}; double[] mealPrices = {35.00, 40.00}; for (int i = 0; i < mealNames.length; i++) { System.out.println(mealNames[i] + " PHP " + mealPrices[i]); }
Indexes start at 0. The last valid index is length - 1. Never use length itself as an index.

7. Public Static Methods

A public static method belongs to the class. Call it without creating an object. Perfect for calculations such as totals and discounts.

public static double calculateTotal(double price, int qty) { return price * qty; } // in main: double total = calculateTotal(50.00, 3);
Return type must match the value you return. Argument count and order must match the parameter list.

8. Modular Design with Public Methods

Keep main focused on setup and printing. Move repeated logic into public static helper methods (applyBulkDiscount, computeGrandTotal, etc.).

public static double applyBulkDiscount(double amount) { if (amount >= 200.00) return amount * 0.85; return amount; }
Pass data in, get a result out. This makes programs easier to test and reuse.
